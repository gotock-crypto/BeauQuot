# BeauQuot

Telegram-бот для публикации качественных вдохновляющих цитат с кинематографичными изображениями без текста.

## Текущая версия

**Visual Engine 3.1.4**.

Версия 3.1.4 сохраняет работающий pipeline 3.1.3 и улучшает прежде всего **semantic art direction**: смысл цитаты сначала превращается в визуальную концепцию, а затем — в одну непрерывную кинематографичную сцену.

## Возможности

- Отбор цитат с оценкой качества и защитой от дублей.
- Анализ темы и настроения цитаты.
- Semantic art direction перед генерацией изображения.
- Temporal semantic composition для цитат с несколькими логическими или временными состояниями.
- Разнообразные визуальные архетипы, чтобы изображения не сводились к одному шаблону вроде `женщина + цветы + золотой свет`.
- Кинематографичные редакционные промпты с явным запретом на текст.
- Несколько попыток генерации изображения с дополнительной проверкой через OCR, если OCR доступен.
- Генерация изображений через Hugging Face с `FLUX.1-schnell` и multi-token failover.
- Семантический анализ через Hugging Face LLM с fallback между настроенными провайдерами/токенами.
- Перевод на русский язык через Google Translate с запасным вариантом через MyMemory.
- История публикаций и визуального разнообразия хранится в SQLite.
- Административное управление через Telegram и настройка интервала автоматических публикаций.

## Semantic art direction 3.1.4

Для цитат с временной или причинной структурой аналитик может определить:

- `clause_count`;
- `temporal_composition`: `none`, `before_after` или `past_present_future`;
- `temporal_beats`.

Если требуется `past_present_future`, визуальная концепция должна содержать три смысловых beat-а — прошлое, настоящее и будущее — **внутри одной непрерывной сцены**.

Запрещены split-screen, триптихи, панели, инфографика и буквальная timeline-графика.

Judge дополнительно проверяет, что красивая, но статичная сцена действительно соответствует смысловой структуре цитаты.

## Требования

Рекомендуется Python 3.10 или новее.

Установите зависимости из `requirements.txt`.

Для дополнительной проверки изображений через `pytesseract` на сервере должен быть установлен Tesseract OCR. Если Tesseract недоступен, бот продолжит работу без OCR-проверки.

## Настройка

Создайте локальный файл `.env` или передайте переменные окружения через платформу, на которой запускается бот:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHANNEL_ID=@BeauQuot
ADMIN_CHAT_ID=0

HF_TOKEN=ваш_токен
HF_TOKEN_2=ваш_резервный_токен
HF_TOKEN_3=ваш_третий_токен
HF_IMAGE_MODEL=black-forest-labs/FLUX.1-schnell
HF_IMAGE_WIDTH=1024
HF_IMAGE_HEIGHT=1280
HF_IMAGE_STEPS=4

TEMPORAL_COMPOSITION_ENABLED=1
TEMPORAL_COMPOSITION_MIN_CLAUSES=2
```

**Не добавляйте в Git:** `.env`, токены, API-ключи, базы данных, автоматически создаваемые конфигурационные файлы и файлы с ID администратора.

### Основные дополнительные переменные

- `DB_FILE` — путь к SQLite-базе.
- `CONFIG_FILE` — файл конфигурации бота.
- `ADMIN_ID_FILE` — файл с ID администратора.
- `QUOTE_CORPUS_FILE` — локальный файл с корпусом цитат.
- `QUOTE_CORPUS_URL` — URL для загрузки корпуса цитат.
- `IMAGE_TIMEOUT` / `HF_IMAGE_TIMEOUT` — тайм-аут генерации изображения.
- `LEXICAL_DUP_THRESHOLD` — порог лексического сходства.
- `SEMANTIC_DUP_THRESHOLD` — порог семантического сходства.
- `RECENT_DIVERSITY_WINDOW` — глубина истории визуального разнообразия.
- `HF_LLM_MODEL` — модель семантического аналитика.
- `HF_LLM_PROVIDERS` — порядок провайдеров LLM.
- `HF_LLM_MAX_TOKENS` — лимит ответа аналитика.
- `HF_LLM_TEMPERATURE` — температура аналитика.
- `TEMPORAL_COMPOSITION_ENABLED` — включает temporal semantic composition.
- `TEMPORAL_COMPOSITION_MIN_CLAUSES` — минимальное количество смысловых частей для temporal composition.

## Запуск

```bash
python main.py
```

При первом использовании `/start`, если ID администратора ещё не настроен, бот назначит первого пользователя администратором.

## Тест изображения

В Telegram используйте кнопку `🧪 Тест картинки`.

Для проверки 3.1.4 особенно полезны цитаты с явной временной или многочастной логикой. Изображение должно оставаться одной непрерывной сценой, а не коллажем.

## Исправление уже опубликованной цитаты

```bash
python main.py repair-published "ТЕКСТ ЦИТАТЫ" "АВТОР"
```

## Как работает генерация

Текст самой цитаты намеренно не передаётся непосредственно в промпт изображения. Сначала определяется эмоциональная и смысловая основа, затем формируется визуальная сцена.

Генератор получает строгий запрет на:

- текст и надписи;
- буквы и цифры;
- типографику;
- водяные знаки и логотипы;
- вывески и плакаты;
- экраны и телефоны с текстом;
- книги, документы, меню и другие объекты с надписями;
- split-screen, триптихи и визуальные панели для temporal composition.

## Обновление production

Архив `quote-bot-v3.1.4-fixed2` распаковывается поверх `/opt/quote-bot`. `.env`, SQLite-база и рабочее состояние не входят в архив.

Перед обновлением production необходимо сделать backup, остановить systemd-сервис, распаковать архив, выполнить `py_compile` и только затем запустить сервис.

Подробная процедура находится в `UPDATE_NOTES_3_1_4.md`.
